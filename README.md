# lab-test-2026-clinic-full

Warmup project for lab test 3 of *High-level programming languages 2*: the **clinic** sample sheet, starting state
**full** (the complete model: you write the repository and the queries).

* The sheet: [test-3-clinic.md](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/sheets/test-3-clinic.md)
* The tutorial of the model and the repository: [model-clinic.md](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/model-clinic.md)
* The tutorials of the queries: [warmup](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/README.md)
* The complete solution: [solutions/clinic](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/solutions/clinic)

Open the project in IntelliJ IDEA with a JDK 25 environment and the *Lombok* plugin enabled. Do not modify the
`base` package and the `data.json`.
